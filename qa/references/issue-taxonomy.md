# QA 问题分类法

## 严重级别

| 严重级别 | 定义 | 示例 |
|----------|------|------|
| **critical** | 阻塞核心流程、导致数据丢失或直接使应用崩溃 | 表单提交后进入错误页、结账流程无法完成、数据被无确认删除 |
| **high** | 重要功能损坏或不可用，且没有可行绕过方式 | 搜索结果错误、文件上传静默失败、登录重定向死循环 |
| **medium** | 功能基本可用，但存在明显问题，且通常有替代路径 | 页面加载过慢（>5s）、缺少校验但仍可提交、仅移动端布局错乱 |
| **low** | 轻微的外观或打磨问题 | 页脚错别字、1px 对齐误差、hover 状态不一致 |

## 分类

### 1. Visual / UI

- 布局破裂，如元素重叠、文字裁切、横向滚动条
- 图片损坏或缺失
- z-index 错乱
- 字体或颜色不一致
- 动画卡顿、过渡不完整
- 对齐问题、栅格不齐、间距不均
- 深色模式或主题样式异常

### 2. Functional

- 链接失效（404、跳错）
- 按钮无效
- 表单校验缺失、错误或可绕过
- 重定向错误
- 状态不持久，刷新或返回后丢数据
- 竞态问题，如重复提交、脏数据
- 搜索结果为空或错误

### 3. UX

- 导航让人困惑，没有面包屑或走到死路
- 缺少 loading 提示
- 交互超过 500ms 且没有反馈
- 错误提示模糊
- 破坏性操作前没有确认
- 不同页面交互模式不一致
- 没有返回路径，也没有下一步行动提示

### 4. Content

- 拼写或语法错误
- 文案过期或错误
- 遗留占位文本 / lorem ipsum
- 文本被截断，且没有省略或展开机制
- 按钮或表单标签错误
- 缺少空状态文案，或空状态无帮助

### 5. Performance

- 页面加载缓慢（>3 秒）
- 滚动掉帧
- 布局抖动
- 单页请求过多（>50）
- 图片过大且未优化
- JavaScript 阻塞，导致页面无响应

### 6. Console / Errors

- JavaScript 异常
- 网络请求失败（4xx、5xx）
- 弃用警告
- CORS 错误
- 混合内容警告
- CSP 违反

### 7. Accessibility

- 图片缺少 alt 文本
- 表单输入缺少标签
- 键盘导航不可用
- 焦点陷阱，无法退出弹窗或下拉框
- ARIA 属性缺失或错误
- 颜色对比度不足
- 屏幕阅读器无法触达内容

## 每个页面的探索清单

QA 过程中，每访问一个页面，都至少检查以下事项：

1. **视觉扫描**：执行带标注截图，检查布局、图像、对齐
2. **交互元素**：点击每个按钮、链接和控件，确认行为与文案一致
3. **表单**：测试空提交、非法数据、长文本、特殊字符等边界
4. **导航**：检查进出路径、面包屑、返回按钮、深链、移动端菜单
5. **状态**：检查空状态、加载态、错误态、满载 / 溢出态
6. **Console**：交互后检查是否出现新的 JS 错误或失败请求
7. **响应式**：必要时检查手机和平板视口
8. **权限边界**：退出登录后会怎样？不同角色会怎样？
